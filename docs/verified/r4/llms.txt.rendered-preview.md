# InHouse Wellness

> InHouse Wellness (https://inhousewellness.com) is a United States retailer of home saunas and cold plunges. It also publishes the Verified Sauna Database: specifications and electrical requirements for home sauna models, each value copied from the manufacturer's own product page or manual, with its source, a grade and the date it was read.

## Verified Sauna Database

- [Verified Sauna Database](https://inhousewellness.com/pages/sauna-database): one row per model with a verified page (brand, heat type, capacity, power supply), each linking to that model's page.
- [How the Sauna Database Is Verified](https://inhousewellness.com/pages/sauna-database-methodology): where values come from, how they are graded, which models get a page and which do not, and how to report a correction.

## How records are verified

- Values come from the manufacturer's own product page (graded Listed) or the manufacturer's own manual or specification sheet (graded Documented).
- Retailer pages are never used as evidence, including InHouse Wellness's own product pages.
- Every value on a model page links its source and shows its grade and the date it was read.
- When no source we could read states a single value, the page says "Not verified" instead of estimating one.
- The same rules apply to every brand, including brands InHouse Wellness sells.
- Corrections are made from the manufacturer's own sources; the methodology page explains how to send one.
