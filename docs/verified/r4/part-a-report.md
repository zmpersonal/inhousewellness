## 3. llms.txt

**What Shopify does today** (verified on this store on 2026-09-29, and in Shopify's documentation):
- `/llms.txt`, `/llms-full.txt` and `/agents.md` all answer 200 with a **Shopify-generated "Agent
  Instructions" document**.
- `robots.txt` points agents at `/agents.md`.
- Shopify has **native support** for replacing these files:
  - [changelog: Customize /llms.txt, /llms-full.txt and /agents.md](https://shopify.dev/changelog/customize-llmstxt-llms-fulltxt-and-agentsmd):
    `templates/agents.md.liquid` controls `/agents.md` and is the default for the other two paths;
    `templates/llms.txt.liquid` controls `/llms.txt` only.
  - [llms.txt.liquid](https://shopify.dev/docs/storefronts/themes/architecture/templates/llms-txt-liquid):
    lookup order `llms.txt.liquid` → `agents.md.liquid` → the Shopify default. The template can't
    be JSON. It renders with a **restricted context**: only `request` and `agents` are available,
    and `shop`, `pages` and similar objects render blank.
  - [agents.md.liquid](https://shopify.dev/docs/storefronts/themes/architecture/templates/agents-md-liquid):
    documents the `agents` object (`store_url`, `ucp_discovery_url`, `mcp_endpoint_url`,
    `sitemap_url`, and others), and **cautions against putting contact email addresses** in these
    files, because they are cached and served to every agent.
- **A URL redirect or an app proxy no longer works** for these paths. Shopify serves them natively
  and they take precedence (community reports; the native path is the documented one).

**Recommendation:** add `templates/llms.txt.liquid` only.
- It changes `/llms.txt` alone. `/agents.md` and `/llms-full.txt` stay Shopify-managed, so the
  commerce and UCP instructions Shopify maintains keep working untouched.
- Our file describes the store and the database in plain text. It keeps the UCP, MCP and sitemap
  pointers through the `agents` object, as Shopify advises, and links to `/agents.md` for store
  interaction.
- It is a theme file, so it would be added to the CLAUDE.md "before any theme is published" list
  and to the theme check.

**Draft:** `docs/verified/r4/llms.txt.liquid.draft`, rendered in `llms.txt.rendered-preview.md`.
- Sections: what InHouse Wellness is, the hub, the methodology, how records are verified, and
  pointers for agents.
- No model count (it would go stale), no price, no email (per Shopify's caution; corrections are
  routed to the methodology page), no "Infinite Sauna". The health gate is clean.
